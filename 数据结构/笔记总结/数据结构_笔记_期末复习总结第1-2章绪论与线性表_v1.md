## 1.1 什么是数据结构

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.1】程序与数据结构的关系</b></p>

1. **核心公式**：<b style="color:#1565c0;">程序 = 数据结构 + 算法</b>（瑞士计算机科学家 **Niklaus Wirth** 提出）
   - **数据结构**：研究数据的**组织**与**存储**方式（数据元素间的关系及其在计算机中的映像）
   - **算法**：研究对数据的**操作**方法（求解步骤的描述）
2. 数据结构的二元组定义：**Data_Structure = (D, S)**，其中 D 是**数据元素的有限集合**，S 是 D 上**关系的有限集合**
3. <b style="color:#c62828;">数据结构三要素：逻辑结构、存储结构（物理结构）、数据的运算</b>
   - **逻辑结构**：描述数据元素之间的逻辑关系，**与存储方式无关**
   - **存储结构**：逻辑结构在计算机中的**物理实现**（映像）
   - **数据的运算**：<b style="color:#c62828;">运算的定义基于逻辑结构，运算的实现基于存储结构</b>
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【理解图示】三要素的层次关系</b></p>

| 逻辑结构 | ⟶ 映射为 ⟶ | 存储结构 | ⟶ 支撑 ⟶ | 数据运算 |
|:---:|:---:|:---:|:---:|:---:|
| 怎么**想** | | 怎么**存** | | 怎么**做** |

同一逻辑结构可对应**多种**存储结构（如线性表既可顺序存储也可链式存储），但运算的**接口（定义）不变**，变化的只是**实现**。
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 1.1】</b></p>

- **填空题**：程序 = ____ + 算法；数据结构的三要素是____、____、____
- **判断题**：数据的运算定义与存储结构无关（✅，运算只由逻辑结构决定）
- **判断题**：一种逻辑结构只能有一种存储结构（❌，可以有多种实现）
</div>

## 1.2 基本概念和术语

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.2-1】概念的层级关系（由大到小）</b></p>

**数据 ⊃ 数据对象 ⊃ 数据元素 ⊃ 数据项**

- **数据**：能输入计算机且被程序处理的**符号总称**（数字、文字、图像等）
- **数据元素**：数据的<b style="color:#c62828;">基本单位</b>，程序中通常作为整体处理（如一条学生记录）
- **数据项**：<b style="color:#c62828;">不可分割的最小单位</b>（如学号、姓名），一个数据元素由若干数据项组成
- **数据对象**：性质相同的**数据元素的集合**，是数据的一个子集

<b style="color:#6e2da0;">口诀：元素是基本单位，项是最小单位；元素由项组成。</b>
</div>

<div style="background:#fef3de;border:1.5px solid #d6740e;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#d6740e;">【易错 1.2-1】</b></p>

- 讨论数据结构时的"基本单位"是**数据元素**，不是数据项——选择题高频偷换概念
- **数据项**是**不可再分**的最小标识单位；若题目说"数据元素是数据的最小单位"，判 ❌
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.2-2】逻辑结构的四类划分（按元素间关系）</b></p>

| 结构类型 | 元素关系 | 典型例子 | 是否线性 |
|:---|:---:|:---|:---:|
| 集合 | 无特定关系，仅同属一个集合 | 集合运算、查找表 | 非线性 |
| **线性结构** | **一对一** | 线性表、栈、队列、串、数组 | 线性 |
| **树形结构** | **一对多** | 二叉树、树、森林 | 非线性 |
| **图状/网状结构** | **多对多** | 有向图、无向图、网 | 非线性 |
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.2-3】存储结构的四类划分（物理实现）</b></p>

| 存储方式 | 核心特点 | 优点 | 缺点 |
|:---|:---|:---|:---|
| **顺序存储** | 连续内存单元；逻辑相邻 ⇔ 物理相邻 | 随机存取快；存储密度高 | 插入/删除需移动大量元素 |
| **链式存储** | 结点 = 数据域 + 指针域；地址不要求连续 | 插入/删除灵活，只改指针 | 不能随机存取；存储密度低（指针开销） |
| **索引存储** | 数据文件 + 索引表（关键字→地址） | 查找速度快 | 额外增加索引表的空间开销 |
| **散列存储** | 由**关键字直接计算**存储地址 | 查找、增删效率极高 | 可能产生**冲突**（同义词） |
</div>

<div style="background:#fef3de;border:1.5px solid #d6740e;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#d6740e;">【易错 1.2-2】逻辑结构 vs 存储结构（高频判断题）</b></p>

- "线性表是顺序存储的"——❌。线性表是**逻辑结构**，顺序表/链表是它的两种**存储实现**
- "栈、队列、串是线性结构"——✅；"二叉树是线性结构"——❌（一对多，树形）
- 逻辑结构**独立于计算机**，存储结构**依赖（面向）计算机**
- 顺序存储**不一定**只能存一维线性表——树也能顺序存储（如二叉树的数组表示，第 6 章）
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 1.2】</b></p>

- **选择题**：区分数据元素与数据项；判断某结构（栈/队列/串/二叉树/图）属于哪类逻辑结构；辨析四种存储结构的特点与优缺点
- **填空题**：逻辑结构分为集合、____、____、____四类
- **判断题**：散列存储不会产生冲突（❌）；链式存储的结点地址可以不连续（✅）
</div>

## 1.3 抽象数据类型（ADT）

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.3】抽象数据类型的三元组</b></p>

- **ADT 三元组**：**ADT = (D, S, P) = 数据对象 + 数据关系 + 基本操作**
  - **D**（数据对象）：元素的取值范围
  - **S**（数据关系）：元素之间的逻辑关系
  - **P**（基本操作）：定义在该对象上的一组操作接口
- ADT 只描述**逻辑特性**（做什么），不关心**具体实现**（怎么做）——体现了**逻辑与物理分离**、**数据封装**与**信息隐蔽**的思想
- 只要数学特性不变，即使更换实现方式（如顺序表换链表），**使用方式不受影响**
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【标准模板】复数 ADT（简答题背诵版，严蔚敏教材原格式）</b></p>

```text
ADT Complex {
    数据对象：D = { e1, e2 | e1, e2 ∈ RealSet }
    数据关系：R1 = { <e1, e2> | e1 是实部, e2 是虚部 }
    基本操作：
        InitComplex( &Z, v1, v2 )
            操作结果：构造复数 Z，其实部和虚部分别被赋以 v1、v2 值。
        DestroyComplex( &Z )
            操作结果：复数 Z 被销毁。
        GetReal( Z, &realPart )
            初始条件：复数 Z 已存在。
            操作结果：用 realPart 返回 Z 的实部值。
        GetImag( Z, &imagPart )
            初始条件：复数 Z 已存在。
            操作结果：用 imagPart 返回 Z 的虚部值。
        Add( z1, z2, &sum )
            初始条件：z1, z2 是复数。
            操作结果：用 sum 返回两个复数 z1、z2 的和值。
} ADT Complex
```
</div>

<div style="background:#fef3de;border:1.5px solid #d6740e;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#d6740e;">【易错 1.3】</b></p>

- "ADT 与计算机内部如何表示和实现有关"——❌，ADT 恰恰**与实现无关**
- ADT 三元组是 **（数据对象、数据关系、基本操作）**，别与数据结构三要素（逻辑结构、存储结构、运算）混淆
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 1.3】</b></p>

- **填空题**：抽象数据类型由____、____、____三部分组成
- **简答题**：写出某 ADT（复数、线性表）的完整定义（按上面模板套）
- **判断题**：ADT 一旦定义，其实现方式就唯一确定（❌）
</div>

## 1.4 算法和算法分析

### 1.4.1 算法的五大特性

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.4-1】算法的五大特性（必背）</b></p>

| 特性 | 要求 | 说明 / 考试细辨 |
|:---|:---|:---|
| **有穷性** | 有限步骤、有限时间内结束 | <b style="color:#c62828;">程序可以不满足</b>（如操作系统无限循环），算法必须满足 |
| **确定性** | 每条指令含义明确、无歧义 | 相同输入 ⇒ 相同输出 |
| **可行性** | 每步都能通过已实现的基本运算完成 | 描述的每个操作都可以兑现执行 |
| **输入** | **0 个或多个** | <b style="color:#c62828;">可以没有输入</b>（如打印固定信息） |
| **输出** | **1 个或多个** | <b style="color:#c62828;">必须有输出</b>（无输出的算法没有意义） |
</div>

<div style="background:#fef3de;border:1.5px solid #d6740e;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#d6740e;">【易错 1.4-1】五大特性 ≠ 四个设计要求（选择题头号坑）</b></p>

- **算法的五大特性**（固有属性）：有穷性、确定性、可行性、输入、输出
- **算法设计的四个要求**（评价标准）：<b style="color:#c62828;">正确性、可读性、健壮性、高效率与低存储量需求</b>
- 命题人常把"正确性""可读性"混进"特性"选项中——遇到"下列不属于算法特性的是"，若选项含**正确性/可读性/健壮性/高效性**，即锁定答案
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.4-2】算法设计四个要求的含义</b></p>

- **正确性**：对**合法输入**能得到满足规格说明的结果；对**非法输入**能给出错误说明
- **可读性**：便于人的阅读、理解和交流（调试与维护的基础）
- **健壮性**（鲁棒性）：遇到非法数据能**妥善处理**而不会莫名其妙崩溃
- **高效率与低存储量**：时间复杂度低、空间复杂度低（二者有时需要权衡）
</div>

### 1.4.2 时间复杂度

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.4-3】大 O 记号的定义</b></p>

设 T(n) 为算法执行时间，f(n) 为某个函数：

- **大 O（上界）**：若存在正常数 c 和 n₀，当 n ≥ n₀ 时有 0 ≤ T(n) ≤ c·f(n)，记 **T(n) = O(f(n))**
- **大 Ω（下界）**：当 n ≥ n₀ 时 T(n) ≥ c·f(n) > 0，记 T(n) = Ω(f(n))
- **大 Θ（同阶）**：c₁·f(n) ≤ T(n) ≤ c₂·f(n)，记 T(n) = Θ(f(n))

不加说明时，讨论的时间复杂度均指<b style="color:#c62828;">最坏情况</b>下的时间上界。
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【核心知识点 1.4-4】复杂度化简三规则 + 增长速度链</b></p>

1. <b style="color:#6e2da0;">加法规则</b>：顺序执行取最大——T₁(n)+T₂(n) = O(max{f(n), g(n)})
2. <b style="color:#6e2da0;">乘法规则</b>：嵌套执行相乘——T₁(n)·T₂(n) = O(f(n)·g(n))
3. <b style="color:#6e2da0;">忽略规则</b>：丢掉常数系数，只保留**最高阶项**；对数的**底数不影响量级**（log₂n 与 ln n 同阶，都记 O(log n)）

**增长速度链（必背）**：

> **O(1) < O(log n) < O(√n) < O(n) < O(n·log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)**
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.4-5】三种时间复杂度</b></p>

- **最坏时间复杂度**：最坏输入下的耗时——<b style="color:#c62828;">考试不作说明时默认写这个</b>
- **平均时间复杂度**：所有可能输入**等概率出现**时的期望耗时
- **最好时间复杂度**：最理想输入下的耗时
- **结论**：平均 ≠ 最坏。例：快速排序平均 O(n·log n)、最坏 O(n²)；冒泡排序（带提前退出）最好 O(n)、最坏 O(n²)
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【典型代码模式速查】由循环结构直接写复杂度</b></p>

| 代码模式 | 执行次数 | 复杂度 |
|:---|:---:|:---:|
| 单语句 / 无循环 | 常数次 | O(1) |
| `for(i=0;i<n;i++)` 单层 | n | O(n) |
| 两层嵌套 `for i, for j`（各 n 次） | n² | O(n²) |
| `for(i=0;i<n;i++) for(j=0;j<m;j++)` | n×m | O(n·m) |
| `while(i<=n) i=i*2;` | ⌈log₂n⌉ | O(log n) |
| `for(i=1;i<=n;i++) for(j=1;j<=i;j++)` | n(n+1)/2 | O(n²) |
| 递归（每层一次调用，递归深度 n） | n | O(n) |
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【真题风格例题】计算时间复杂度（期末必出题型）</b></p>

**例 1**

```c
int s = 0;
for (int i = 1; i <= n; i++)      // 执行 n 次
    for (int j = 1; j <= i; j++)  // 内层执行 i 次
        s++;
```

总次数 = 1 + 2 + … + n = n(n+1)/2，取最高阶 → **O(n²)**

**例 2**

```c
int i = 1;
while (i <= n)
    i = i * 2;   // 每次翻倍
```

设执行 t 次后 2ᵗ > n，即 t = ⌈log₂n⌉ → **O(log₂n)**

**例 3（递归）**

```c
int fact(int n) {
    if (n <= 1) return 1;   // 递归出口
    return n * fact(n - 1); // 每次规模减 1，共递归 n 层
}
```

递归深度为 n，每层基本操作 O(1) → **时间 O(n)，空间 O(n)（递归工作栈）**
</div>

### 1.4.3 空间复杂度

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 1.4-6】空间复杂度</b></p>

- **空间复杂度 S(n)**：衡量算法运行时<b style="color:#c62828;">额外</b>占用的辅助存储空间（**不含**输入数据本身所占的空间）
- **原地工作**：所需额外空间与问题规模 n 无关，即 S(n) = O(1)
- **递归算法**：需要递归工作栈，空间复杂度 ≈ **递归深度**（如 `fact(n)` 的 S(n)=O(n)）
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 1.4】</b></p>

- **简答题**：简述算法的五大特性 / 算法设计的四个目标（注意题目问的是哪一个）
- **选择题**：下列不属于算法特性的是（正确性/可读性/健壮性……）；给代码段求时间复杂度；复杂度增长速度排序；判断是否为原地工作
- **判断题**：算法必须有输入（❌，0 个或多个）；算法必须有输出（✅）
- **填空题**：快速排序平均时间复杂度为____，最坏为____
</div>

<h2 style="color:#1565c0;border-bottom:3px solid #1565c0;padding-bottom:4px;">第二章　线性表</h2>

## 2.1 线性表的类型定义

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.1-1】线性表的定义</b></p>

- **定义**：n（n ≥ 0）个数据元素组成的<b style="color:#c62828;">有限序列</b>，记作 (a₁, a₂, …, aᵢ₋₁, aᵢ, aᵢ₊₁, …, aₙ)
  - n 为**表长**，n=0 时为**空表**；aᵢ 是第 i 个元素，i 称为其**位序**（<b style="color:#c62828;">从 1 开始，不是 0</b>）
- 元素间为**一对一**的线性关系：
  - 有且仅有一个**开始结点** a₁（无前驱）和一个**终端结点** aₙ（无后继）
  - 除 a₁ 外每个元素有**唯一**前驱；除 aₙ 外每个元素有**唯一**后继
</div>

<div style="background:#fef3de;border:1.5px solid #d6740e;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#d6740e;">【易错 2.1】</b></p>

- 线性表的元素个数**必须有限**（"可以是无限的"判 ❌）
- "线性表中每个元素都有一个直接前驱和一个直接后继"——❌，首、尾元素各缺一个
- **同一线性表中元素类型相同**（属于同一数据对象）
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.1-2】线性表的基本操作（创销、增删改查）</b></p>

| 操作函数 | 类别 | 功能 |
|:---|:---:|:---|
| `InitList(&L)` | 创 | 初始化空表，分配内存空间 |
| `DestroyList(&L)` | 销 | 销毁表，释放占用的内存 |
| `ClearList(&L)` | 清 | 清空表中元素（表仍存在） |
| `ListInsert(&L, i, e)` | 增 | 在第 i 个位置**之前**插入元素 e，长度加 1 |
| `ListDelete(&L, i, &e)` | 删 | 删除第 i 个元素，用 e 返回其值，长度减 1 |
| `GetElem(L, i, &e)` | 查（按位） | 取第 i 个位置元素的值 |
| `LocateElem(L, e)` | 查（按值） | 返回第一个与 e 相等的元素的位序 |
| `ListLength(L)` | 其他 | 返回线性表的长度 |
| `ListEmpty(L)` | 其他 | 判表空（空返回 TRUE） |

**参数约定**：<b style="color:#1565c0;">&</b> 表示**引用型参数**——结果要带回主函数（C 语言用**指针**实现）；无 & 的参数只把值传进去用（值传递，修改不影响主调函数）
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 2.1】</b></p>

- **填空题**：线性表是<b style="color:#1565c0;">一对一</b>关系的<b style="color:#1565c0;">有限</b>序列；写出在第 i 个位置插入元素的函数名
- **判断题**：线性表的元素个数可以是无限的（❌）
- **简答题**：简述线性表的基本操作；解释 `&` 参数的含义
</div>

## 2.2 线性表的顺序表示（顺序表）

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.2-1】存储结构与随机存取</b></p>

- 用<b style="color:#1565c0;">一段地址连续的存储单元</b>依次存储线性表元素（数组实现），<b style="color:#c62828;">逻辑相邻 ⇔ 物理相邻</b>
- **随机存取**（顺序表最大优点）：任一元素 O(1) 定位。设每个元素占 L 个存储单元，首元素地址为 LOC(a₁)，则

  > **LOC(aᵢ) = LOC(a₁) + (i−1) × L**

- 结构定义（严蔚敏标准写法）：

```c
#define MAXSIZE 100                // 顺序表的最大容量
typedef struct {
    ElemType elem[MAXSIZE];        // 存储元素的数组
    int          length;           // 当前表长（元素个数）
} SqList;                          // 顺序表类型
```
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.2-2】插入与删除的元素移动分析（计算题高频）</b></p>

- **插入**（在第 i 位插入）：第 n ~ i 位元素**整体后移一位**（从最后一个开始从后往前移），移动 n−i+1 个元素；合法范围 <b style="color:#c62828;">1 ≤ i ≤ n+1</b>
- **删除**（删第 i 位）：第 i+1 ~ n 位元素**整体前移一位**，移动 n−i 个元素；合法范围 <b style="color:#c62828;">1 ≤ i ≤ n</b>
- 等概率下（插入 n+1 个位置、删除 n 个位置等概率）：

  > 插入平均移动 **n/2** 个，删除平均移动 **(n−1)/2** 个，时间复杂度均为 <b style="color:#c62828;">O(n)</b>

- 按位查找 `GetElem`：**O(1)**；按值查找 `LocateElem`：**O(n)**（无序时需遍历）
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背算法】顺序表的插入与删除（期末算法题模板）</b></p>

**插入**：在顺序表 L 的第 i 位插入 e

```c
Status ListInsert_Sq(SqList *L, int i, ElemType e) {
    int j;
    if (i < 1 || i > L->length + 1) return ERROR;   // i 不合法
    if (L->length >= MAXSIZE)        return ERROR;   // 表满（溢出）
    for (j = L->length - 1; j >= i - 1; j--)         // 元素从后向前依次后移
        L->elem[j + 1] = L->elem[j];                 //   下标 n-1 .. i-1 -> i .. n
    L->elem[i - 1] = e;                              // 放入新元素（位序 i -> 下标 i-1）
    L->length++;                                     // 表长加 1
    return OK;
}
```

**删除**：删除第 i 位元素，用 e 返回

```c
Status ListDelete_Sq(SqList *L, int i, ElemType *e) {
    int j;
    if (i < 1 || i > L->length) return ERROR;        // i 不合法性检查
    *e = L->elem[i - 1];                             // 保存被删元素的值
    for (j = i; j <= L->length - 1; j++)             // 元素从前向后依次前移
        L->elem[j - 1] = L->elem[j];                 //   下标 i .. n-1 -> i-1 .. n-2
    L->length--;                                     // 表长减 1
    return OK;
}
```

<b style="color:#6e2da0;">位序与下标换算：位序 i 对应数组下标 i−1，这是顺序表代码题最常见的笔误点！</b>
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.2-3】顺序表的优缺点与适用场景</b></p>

| 优点 | 缺点 |
|:---|:---|
| ✅ 支持**随机存取**，按位存取 O(1) | ❌ 插入/删除需移动大量元素，平均移动 n/2 个，O(n) |
| ✅ **存储密度高**（= 数据本身存储量 / 结点总存储量，无指针开销） | ❌ 需**预先分配**连续空间，容量难以估计 |
| ✅ 逻辑关系隐含在物理位置中，无需额外存储关系信息 | ❌ 容量固定易溢出；空间利用不灵活 |

**适用场景**：表长可预估、存取（查询）操作远多于插入删除；如频繁按位取元素、有序表折半查找
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 2.2】</b></p>

- **选择题**：顺序表最主要的优点（随机存取）；插入/删除的时间复杂度（O(n)）；在长度为 n 的顺序表第 i 位插入需移动____个元素（n−i+1）
- **计算题**：含 100 个元素的顺序表，等概率下插入平均移动 50 个、删除平均移动 49.5 个元素
- **简答题**：简述顺序存储结构的优缺点（套用上表，先答"逻辑相邻=物理相邻"的定义句）
- **算法题**：写出顺序表的插入/删除算法（含合法性检查 + 移动方向两步，别漏！）
</div>

## 2.3 线性表的链式表示（链表）

### 2.3.1 单链表（线性链表）

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.3-1】结点结构与头指针/头结点辨析</b></p>

- 每个结点 = <b style="color:#1565c0;">数据域 data</b> + <b style="color:#1565c0;">指针域 next</b>（存后继结点地址）；结点间的逻辑关系由指针维系，**存储空间不必连续**

```c
typedef struct LNode {
    ElemType      data;    // 数据域
    struct LNode *next;    // 指针域：指向后继结点
} LNode, *LinkList;        // LinkList 即 LNode*（头指针）
```

- 三个概念<b style="color:#c62828;">高频辨析</b>：
  - **头指针**：指向链表第一个结点的指针；**无论有无头结点都存在**，且**恒不为空**，是链表的标识
  - **头结点**：人为附加在首元结点**之前**的结点，数据域一般不存实质数据（可存表长等附加信息）
  - **首元结点**：存放第一个数据元素 a₁ 的结点
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背结论】头结点的两大作用（简答题模板）</b></p>

1. <b style="color:#6e2da0;">统一操作</b>：使空表与非空表的处理一致（带头结点时空表与非空表的首元插入逻辑相同）
2. <b style="color:#6e2da0;">简化算法</b>：首元结点的插入/删除不再需要特殊处理，任何位置的插入/删除统一为"修改前驱结点的指针"

**对比记忆**：不带头结点时，在第 1 位插入要修改**头指针**，其余位置修改前驱的 `next`——逻辑分叉，容易出错
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.3-2】单链表的操作与复杂度</b></p>

| 操作 | 做法 | 复杂度 |
|:---|:---|:---:|
| 按位查找 `GetElem` | 从头结点起顺指针扫描 i 步 | O(n) |
| 按值查找 `LocateElem` | 从首元起逐一比较 | O(n) |
| 插入（**已知前驱** p） | 只改两根指针 | <b style="color:#c62828;">O(1)</b> |
| 删除（**已知前驱** p） | 只改指针 + `free` | <b style="color:#c62828;">O(1)</b> |
| 插入/删除（**不知位置**） | 先查找前驱再操作 | O(n)（查找主导） |
</div>

<div style="background:#fef3de;border:1.5px solid #d6740e;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#d6740e;">【易错 2.3-1】"链表插入删除是 O(1)"的说法是错的！</b></p>

<b style="color:#c62828;">O(1) 仅指指针修改本身</b>。若不知道位置，需先从头遍历找前驱（O(n)），总耗时 O(n)。

判断题标准答案："单链表插入删除时间复杂度为 O(1)"——❌（要分"是否已定位"两种情况讨论）。单链表**不支持随机存取**（顺序表才支持），这也是选择题常考对比点。
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背算法 1】单链表的插入、删除与"前插"技巧</b></p>

**后插**（在 p 结点之后插入 s）——<b style="color:#6e2da0;">先接新，后拆旧</b>：

```c
s->next = p->next;      // (1) s 先抓住房东的下一个
p->next = s;            // (2) 再让房东指向 s
// 两句顺序不可颠倒！颠倒将丢失 p 原来的后继
```

**删除** p 的后继 q：

```c
q = p->next;            // q 暂存待删结点
p->next = q->next;      // 跨接：p 直指 q 的后继
free(q);                // 释放结点（严蔚敏：标准写法必写）
```

**前插技巧（偷天换日）**：要在 p 之前插入 s 而不知前驱时，可先**后插** s，再**交换** p、s 的 `data`，实现 O(1) 前插。
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背算法 2】建表：头插法（逆序）与尾插法（正序）</b></p>

```c
// 头插法：读入 a1..an，生成的链表为 an..a1（逆序）——可用来"逆置"
void CreateList_Head(LinkList L, int n) {
    LinkList p; int i;
    L->next = NULL;                    // 先建空表
    for (i = 0; i < n; i++) {
        p = (LinkList)malloc(sizeof(LNode));
        scanf("%d", &p->data);         // 读入新结点
        p->next = L->next;             // 新结点接管首元
        L->next = p;                   // 头结点指向新结点
    }
}

// 尾插法：附设尾指针 r，始终指向表尾，生成正序链表
void CreateList_Tail(LinkList L, int n) {
    LinkList p, r; int i;
    r = L;                             // r 初值为头指针（表尾）
    for (i = 0; i < n; i++) {
        p = (LinkList)malloc(sizeof(LNode));
        scanf("%d", &p->data);
        r->next = p;                   // 挂到表尾
        r = p;                         // r 后移指向新表尾
    }
    r->next = NULL;                    // 收尾：尾结点指针域置空（易漏！）
}
```

<b style="color:#6e2da0;">口诀：头插逆序，尾插正序；尾插最后别忘 `r->next=NULL`。</b>
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背算法 3】单链表逆置（就地，O(n)）——期末高频算法题</b></p>

思路：摘下头结点建立空表，把原链结点依次**头插**进来，即完成逆置。

```c
void ReverseList(LinkList L) {      // 带头结点的单链表就地逆置
    LinkList p, q;
    p = L->next;                    // p 指向原首元结点
    L->next = NULL;                 // 摘下头结点，建立空表
    while (p != NULL) {
        q = p->next;                // 暂存 p 的后继，防止断链
        p->next = L->next;          // p 头插到新表
        L->next = p;
        p = q;                      // 继续处理下一个
    }
}
```
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背算法 4】两个有序链表的归并（保留递增序，利用原结点）——必考</b></p>

```c
// 将递增有序的 La、Lb 归并为递增有序的 Lc（严蔚敏算法 2.12）
void MergeList_L(LinkList La, LinkList Lb, LinkList *Lc) {
    LinkList pa = La->next, pb = Lb->next, pc;
    pc = La;                        // 用 La 的头结点作 Lc 的头结点
    *Lc = pc;
    while (pa && pb) {              // 两表均不空时，摘小者接到 Lc 尾
        if (pa->data <= pb->data) { pc->next = pa; pc = pa; pa = pa->next; }
        else                       { pc->next = pb; pc = pb; pb = pb->next; }
    }
    pc->next = pa ? pa : pb;        // 挂上剩余段（只挂一段！）
    free(Lb);                       // 释放 Lb 的头结点
}
```

**考点追问**：
1. 时间复杂度 O(m+n)，空间复杂度 O(1)（原地归并，不申请新结点）
2. 要**递减**输出怎么办？——归并时改取较大者即可
3. 空间复杂度变 O(m+n) 的写法是**申请新结点**复制数据（该版利用原结点，故为 O(1)）
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 2.3-1】单链表</b></p>

- **选择题**：头结点的作用；单链表能否随机存取（不能）；`s->next=p->next; p->next=s;` 的执行顺序辨析；头插/尾插生成的次序
- **判断题**：链表插入删除为 O(1)（❌，须讨论是否先查找）
- **算法题（高频必考）**：单链表的插入、删除、**逆置**、有序**归并**、按值/按位查找、求表长（沿 `next` 数到 `NULL`）、找中间结点（快慢指针，见下）
- **程序填空**：给算法挖空（多为指针修改的 4 句关键代码）
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【加分拓展】快慢指针两个经典小题（很多期末卷当附加题）</b></p>

1. **找中间结点**：`fast` 每次走 2 步、`slow` 每次走 1 步，`fast` 到尾时 `slow` 恰在中点，时间 O(n)、空间 O(1)
2. **判环**：`fast`、`slow` 同出发，若二者**再次相遇**则链有环
</div>

### 2.3.2 循环链表

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.3-3】循环（单）链表</b></p>

- **定义**：表中**最后一个结点的 `next` 指向头结点**，整个链表构成一个环
- **特点**：从表中<b style="color:#c62828;">任一结点出发都能遍历整个链表</b>（单链表做不到，会走到 `NULL` 截止）
- **判空条件**：<b style="color:#c62828;">`L->next == L`</b>（头结点的 `next` 指向自身）
- 终止条件由"指针是否为空"变为"指针是否**等于头指针**"
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背算法】带尾指针的两个循环链表的合并（O(1)，经典简答/算法题）</b></p>

设 `Ra`、`Rb` 分别为两个循环链表**的尾指针**（表头即 `Ra->next`、`Rb->next`）：

```c
LinkList p, q;
p  = Ra->next;              // (1) p 暂存 A 表的头结点
Ra->next = Rb->next->next;  // (2) B 的首元结点接到 A 的表尾
q  = Rb->next;              // (3) q 暂存 B 的头结点
Rb->next = p;               // (4) B 的表尾指向 A 的头结点，成环
free(q);                    // (5) 释放 B 的头结点
```

**考点追问**：为什么用**尾指针**而不是头指针？——尾指针可 O(1) 定位表头（`rear->next`）和表尾（`rear`）；若只有头指针，找 A 的表尾需 O(n)。
</div>

### 2.3.3 双向链表

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.3-4】双向（循环）链表</b></p>

- 结点结构 = 数据域 + <b style="color:#1565c0;">前驱指针 prior</b> + <b style="color:#1565c0;">后继指针 next</b>：

```c
typedef struct DuLNode {
    ElemType        data;
    struct DuLNode *prior, *next;   // 前驱与后继指针
} DuLNode, *DuLinkList;
```

- 双向链表**牺牲空间换时间**：可 O(1) 找到前驱（弥补单链表找前驱 O(n) 的痛点）
- 双向**循环**链表判空：`L->next == L && L->prior == L`
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背算法】双向链表的插入与删除（指针顺序是期末最爱挖空处）</b></p>

**在 p 结点之后插入 s**（四步，<b style="color:#6e2da0;">先安顿新结点，再动旧邻居</b>）：

```c
s->prior = p;                // (1) s 认 p 作前驱
s->next  = p->next;          // (2) s 认 p 的后继作后继
p->next->prior = s;          // (3) 后继回头认 s
p->next  = s;                // (4) 最后才让 p 指向 s
```

**删除 p 结点**（两句，先改前驱再改后继，顺序可互换）：

```c
p->prior->next = p->next;    // p 的前驱跨过 p
p->next->prior = p->prior;   // p 的后继跨过 p
free(p);
```

**自检口诀**：插入 4 句中 `(4) p->next = s` 若提前到 `(2)` 之前，p 的原后继将失联断链——做题时画 3 个结点的示意图逐一验证。
</div>

### 2.3.4 静态链表（拓展，部分院校考概念）

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.3-5】静态链表</b></p>

- 用**数组**描述链表：结点含 `data` 和 `cursor`（<b style="color:#1565c0;">游标</b>，即<b style="color:#c62828;">后继结点在数组中的下标</b>，代替指针）
- 适用于**不支持指针的高级语言**（如早期 BASIC、Fortran）
- 优缺点：插入删除**只需改游标、不需移动元素**（像链表）；但**需预先分配大块连续空间**、不能随机存取（像顺序表）
- **辨析题**：静态链表中的"指针"其实是**数组下标（游标）**
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 2.3-2】循环链表、双向链表、静态链表</b></p>

- **选择题**：循环链表判空条件（`L->next==L`）；带尾指针循环链表合并的时间复杂度（O(1)）；双向链表插入的指针修改顺序（排序题/填空题）；静态链表的"指针"本质（游标/下标）
- **判断题**：双向链表任一结点均可 O(1) 找到其前驱（✅）
- **算法题**：双向链表的插入/删除（背上面 4 句 + 2 句）
</div>

## 2.4 顺序表与链表的全面对比（简答题高频）

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.4】顺序表 vs 单链表（必背总表）</b></p>

| 对比项 | 顺序表（顺序存储） | 单链表（链式存储） |
|:---|:---|:---|
| 空间分配 | 静态分配（**预先**分配连续空间）；易溢出或浪费 | 动态分配（`malloc` 按需申请）；只要内存够就不满 |
| 存储密度 | 高（=1，无额外指针开销） | 低（每个结点**多一个指针域**） |
| 存取方式 | ✅ **随机存取**，O(1) | ❌ **顺序存取**，只能从头找起，O(n) |
| 按位查找 | O(1) | O(n) |
| 按值查找 | 无序 O(n)（有序可折半 O(log n)） | O(n) |
| 插入/删除 | 移动元素，平均 n/2 个，O(n) | 已定位处只改指针 O(1)；定位需 O(n) |
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【简答题模板】"简述顺序表和链表的区别并说明各自适用场景"</b></p>

**答题四步**（先定义、再对比、后结论、给场景）：

1. **定义句**：顺序表用一段**地址连续**的存储单元依次存放元素，逻辑相邻即物理相邻；链表用一组**任意存储单元**存放结点（数据域+指针域），靠指针维系逻辑关系
2. **优点对比**：顺序表支持随机存取（O(1)）、存储密度高；链表插入删除只改指针、容量动态可扩
3. **缺点对比**：顺序表插删需移动约 n/2 个元素、需预估容量；链表不可随机存取、有指针空间开销
4. **场景结论**：✅ **查询多、插删少、长度稳定 → 顺序表**；✅ **插删频繁、长度变化大 → 链表**
</div>

<div style="background:#fef3de;border:1.5px solid #d6740e;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#d6740e;">【易错 2.4】</b></p>

- "链表一定比顺序表省空间"——❌：链表有指针域开销；只有当装填不满时链表才可能更省
- "顺序表查找一定比链表快"——❌：**按值**查找（无序时）都是 O(n)；顺序表快在**按位**（随机存取）
- 存储密度定义：**存储密度 = 数据本身所占存储量 / 结点结构总存储量**；顺序表 =1，链表 <1
</div>

## 2.5 一元多项式的表示及相加

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【核心知识点 2.5-1】一元多项式的链式表示</b></p>

- 多项式 Pₙ(x) = p₁xᵉ¹ + p₂xᵉ² + … + pₘxᵉᵐ（按指数**递增**存放），只存<b style="color:#1565c0;">系数非零</b>的项，每个结点含两个数据项：

```c
typedef struct PNode {       // 多项式结点
    float coef;              // 系数 coefficient
    int   expn;              // 指数 exponent
    struct PNode *next;
} PNode, *Polynomial;
```

- **为什么用链表**：项数（非零项个数）动态变化大，且常做插项/删项操作——链表最适配
</div>

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【必背算法】多项式相加（双指针归并，思想与有序表归并同源）</b></p>

设 `pa`、`pb` 分别指向两多项式**当前项**，比较二者的指数 `expn`：

| 比较结果 | 处理 |
|:---|:---|
| `pa->expn == pb->expn` | 系数相加：和 ≠ 0 则改写 `pa` 的系数后保留、两指针同后移；和 = 0 则**删除该项**（释放结点），两指针同后移 |
| `pa->expn < pb->expn` | `pa` 指数小，**原样摘入结果**，`pa` 后移 |
| `pa->expn > pb->expn` | `pb` 指数小，把 `pb` 结点**插入结果中 pa 之前**，`pb` 后移 |
| 一方扫完 | 把另一方**剩余段**整个链到结果末尾 |

**教材经典例**（严蔚敏）：A(x) = 7 + 3x + 9x⁸ + 5x¹⁷，B(x) = 8x + 22x⁷ − 9x⁸，相加得 ✅ **C(x) = 7 + 11x + 22x⁷ + 5x¹⁷**（9x⁸−9x⁸ 抵消删除）
</div>

<div style="background:#ffebec;border:1.5px solid #c62828;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#c62828;">【考法 2.5】</b></p>

- **选择题**：一元多项式适合的存储结构（链表，项数动态变化）；结点应存哪些信息（系数 + 指数 + 指针）；相加算法的时间复杂度（O(m+n)）
- **简答题**：简述一元多项式相加的算法步骤（背上表四种情况）
- **算法题**：写出多项式相加/相乘的核心循环（相乘 = 固定一项乘另一多项式 + 结果归并同类项）
</div>

### 判断正误（每题均附解析）

1. 链表的每个结点中都恰好包含一个指针。　**（❌）**
   > 解析：链表的结点可含**多个**指针域，分别存放多个指针。例如双向链表的结点含有两个指针域，分别存放指向其**直接前驱**和**直接后继**结点的指针。

2. 链表的物理存储结构具有同链表一样的顺序。　**（❌）**
   > 解析：链表各结点的存储空间**可以不连续、无序**，元素间的先后关系完全靠指针维系；"看起来有序"只是示意图的画法而已。

3. 链表的删除算法很简单，因为当删除链中某个结点后，计算机会自动地将后续的各个单元向前移动。　**（❌）**
   > 解析：链表删除**只修改指针内容，结点本身不会移动**；"后续单元前移"是顺序表删除的操作（且也不是"自动"的，需循环逐个前移）。

4. 线性表的每个结点只能是一个简单类型，而链表的每个结点可以是一个复杂类型。　**（❌）**
   > 解析：混淆了逻辑结构与存储结构——**链表本身也是线性表的一种（链式）存储实现**；且即使是顺序表，同样可以存放记录型（复杂类型）的数据元素。

5. 顺序表结构适宜于进行顺序存取，而链表适宜于进行随机存取。　**（❌）**
   > 解析：正好说反了：**顺序表**才支持随机存取（O(1) 按位定位）；**链表**恰恰只能"顺藤摸瓜"从头顺序存取。

6. 顺序存储方式的优点是存储密度大，且插入、删除运算效率高。　**（❌）**
   > 解析：前一半正确；后一半错误——插删效率高是**链式存储**的优点。表长为 n 的顺序表中插删一个元素，**平均需移动 n/2 个元素**。

7. 线性表在物理存储空间中也一定是连续的。　**（❌）**
   > 解析：线性表有**两种存储方式**：顺序存储（连续）与链式存储（不要求连续）。

8. 线性表在顺序存储时，逻辑上相邻的元素未必在存储的物理位置次序上相邻。　**（❌）**
   > 解析：顺序存储时**逻辑相邻 ⇔ 物理相邻**，这正是它的定义；"未必相邻"说的是链式存储。

9. 顺序存储方式只能用于存储线性结构。　**（❌）**
   > 解析：顺序存储也能存放**非线性结构**，例如完全二叉树属于非线性结构，其最佳存储方式恰是顺序存储（第 6 章介绍）。

10. 线性表的逻辑顺序与存储顺序总是一致的。　**（❌）**
    > 解析：链式存储时结点物理位置可以任意，与逻辑顺序**无需一致**（理由同第 7 题）。

### 单项选择题（每题均附解析）

1. 数据在计算机存储器内表示时，物理地址与逻辑地址相同并且是连续的，称之为：　**（C）**
   > （A）存储结构　（B）逻辑结构　（C）**顺序存储结构**　（D）链式存储结构
   > 解析：物理位置**连续**且**次序与逻辑次序一致**，正是顺序存储结构的定义。

2. 一个向量第一个元素的存储地址是 100，每个元素的长度为 2，则第 5 个元素的地址是：　**（B）**
   > （A）110　（B）**108**　（C）100　（D）120
   > 解析：LOC(a₅) = LOC(a₁) + (5−1)×2 = 100 + 8 = 108。套随机存取地址公式即可。

3. 在 n 个结点的顺序表中，算法的时间复杂度是 O(1) 的操作是：　**（A）**
   > （A）**访问第 i 个结点（1≤i≤n）和求第 i 个结点的直接前驱（2≤i≤n）**
   > （B）在第 i 个结点后插入一个新结点（1≤i≤n）　（C）删除第 i 个结点（1≤i≤n）　（D）将 n 个结点从小到大排序
   > 解析：顺序表随机存取：访问第 i 个结点、其前驱（第 i−1 个）都由地址公式直接算出，O(1)；插入/删除需移动元素 O(n)；排序至少 O(n·log n)。

4. 向一个有 127 个元素的顺序表中插入一个新元素并保持原来顺序不变，平均要移动____个元素：　**（B）**
   > （A）8　（B）**63.5**　（C）63　（D）7
   > 解析：等概率下插入平均移动 n/2 = 127/2 = 63.5 个元素（插入位置 1 到 128 等概率）。注意结果**可以是小数**。

5. 链接存储的存储结构所占存储空间：　**（A）**
   > （A）**分两部分：一部分存放结点值，另一部分存放表示结点间关系的指针**
   > （B）只有一部分，存放结点值　（C）只有一部分，存放表示结点间关系的指针　（D）分两部分：一部分存放结点值，另一部分存放结点所占单元数
   > 解析：链式结点 = **数据域 + 指针域**，正是"分两部分"的表述。

6. 线性表若采用链式存储结构时，要求内存中可用存储单元的地址：　**（D）**
   > （A）必须是连续的　（B）部分地址必须是连续的　（C）一定是不连续的　（D）**连续或不连续都可以**
   > 解析：链表靠指针维系逻辑关系，结点地址**连续与否均可**——"必须不连续"同样是错误限制。

7. 线性表 L 在____情况下适用于使用链式结构实现：　**（B）**
   > （A）需经常修改 L 中的结点值　（B）**需不断对 L 进行删除、插入**
   > （C）L 中含有大量的结点　（D）L 中结点结构复杂
   > 解析：插删频繁是选链表的标志场景（只改指针不移动元素）；修改结点值两种结构都需先定位，无差别。

8. 单链表的存储密度：　**（C）**
   > （A）大于 1　（B）等于 1　（C）**小于 1**　（D）不能确定
   > 解析：存储密度 = 数据本身存储量 / 结点总存储量。单链表每个结点都有指针域开销，故**恒小于 1**；顺序表无指针开销，等于 1。

9. 设 a₁、a₂、a₃ 为 3 个结点，整数 P₀、3、4 代表地址，则如下的链式存储结构称为：　**（B）**

   | 头指针 | 结点地址 | 数据域 | 指针域 next |
   |:---:|:---:|:---:|:---:|
   | P₀ → | P₀ | a₁ | 3 |
   | | 3 | a₂ | 4 |
   | | 4 | a₃ | 0（NULL） |

   > （A）循环链表　（B）**单链表**　（C）双向循环链表　（D）双向链表
   > 解析：每个结点只有**一个**指针域（排除双向），尾结点 next 为 0（NULL，排除循环）⇒ 单链表。若尾指针指回**头结点**才是循环链表。

10. 下面关于线性表的叙述中，**错误**的是哪一个？　**（B）**
    > （A）线性表采用顺序存储，必须占用一片连续的存储单元。
    > （B）**线性表采用顺序存储，便于进行插入和删除操作。**
    > （C）线性表采用链接存储，不必占用一片连续的存储单元。
    > （D）线性表采用链接存储，便于插入和删除操作。
    > 解析：B 反了：顺序存储插删要移动大量元素，**不**便于插删——这正是链式存储的便利之处。A、C、D 均为正确叙述。

11. 线性表是具有 n 个____的有限序列（n>0）：　**（C）**
    > （A）表元素　（B）字符　（C）**数据元素**　（D）数据项
    > 解析：标准定义：n 个**数据元素**的有限序列。数据项是更小的单位（元素的一个字段），别混淆。

12. 若某线性表最常用的操作是**存取任一指定序号的元素**和**在最后进行插入、删除**运算，则利用____存储方式最节省时间：　**（A）**
    > （A）**顺序表**　（B）双链表　（C）带头结点的双循环链表　（D）单循环链表
    > 解析：按序号存取要**随机存取**——只有顺序表 O(1)；且尾部插删恰好**不需移动任何元素**（插入位 n+1、删除位 n 都移动 0 个），顺序表完美契合。

13. 某线性表中最常用的操作是**在最后一个元素之后插入一个元素**和**删除第一个元素**，则采用____存储方式最节省运算时间：　**（D）**
    > （A）单链表　（B）仅有头指针的单循环链表　（C）双链表　（D）**仅有尾指针的单循环链表**
    > 解析：尾指针 `rear` 直接就是尾结点（尾插 O(1)）；`rear->next` 是头结点，`rear->next->next` 即首元结点（删首 O(1)）。仅带头指针时找尾要转一圈 O(n)。

14. 静态链表中指针表示的是：　**（B）**
    > （A）内存地址　（B）**数组下标**　（C）下一元素地址　（D）左、右孩子地址
    > 解析：静态链表用数组实现，"指针"实为**游标（后继结点的数组下标）**，不是内存地址。

15. 链表**不具有**的特点是：　**（B）**
    > （A）插入、删除不需要移动元素　（B）**可随机访问任一元素**
    > （C）不必事先估计存储空间　（D）所需空间与线性长度成正比
    > 解析：链表只能从头顺序查找，**不支持随机访问**——这是它相对顺序表的最大短板。A、C、D 都是链表的特点。

16. 完成在双循环链表结点 `p` 之后插入 `s` 的操作是：　**（D）**
    > （A）`p^.next:=s; s^.priou:=p; p^.next^.priou:=s; s^.next:=p^.next;`
    > （B）`p^.next^.priou:=s; p^.next:=s; s^.priou:=p; s^.next:=p^.next;`
    > （C）`s^.priou:=p; s^.next:=p^.next; p^.next:=s; p^.next^.priou:=s;`
    > （D）**`s^.priou:=p; s^.next:=p^.next; p^.next^.priou:=s; p^.next:=s;`**
    > 解析：正序口诀"先安顿新结点，再动旧邻居"：先把 s 的 `priou`、`next` 都接好，再让 p 的原后继回头认 s（`p^.next^.priou:=s`），**最后**才 `p^.next:=s`。A/B/C 都在第 3 步之前就改了 `p^.next`，导致原后继失联断链。

17. 在单链表指针为 `p` 的结点之后插入指针为 `s` 的结点，正确的操作是：　**（B）**
    > （A）`p->next=s; s->next=p->next;`　（B）**`s->next=p->next; p->next=s;`**
    > （C）`p->next=s; p->next=s->next;`　（D）`p->next=s->next; p->next=s;`
    > 解析：必须**先**让 s 抓住 p 的原后继，**再**让 p 指向 s；A 选项第一句就把 `p->next` 覆盖了，第二句 `s->next=p->next` 变成 `s->next=s`，自己指向自己。

18. 对于一个头指针为 `head` 的**带头结点**的单链表，判定该表为空表的条件是：　**（B）**
    > （A）`head==NULL`　（B）**`head->next==NULL`**
    > （C）`head->next==head`　（D）`head!=NULL`
    > 解析：头指针**恒不为 NULL**（它指向头结点），故 A 必错；空表 = 头结点的 `next` 为空。注意 C（`head->next==head`）是**循环链表**的判空条件——高频混淆点！

19. 在双向链表存储结构中，删除 `p` 所指的结点时须修改指针：　**（A）**
    > （A）**`(p^.llink)^.rlink:=p^.rlink; (p^.rlink)^.llink:=p^.llink;`**
    > （B）`p^.llink:=(p^.llink)^.llink; (p^.llink)^.rlink:=p;`
    > （C）`(p^.rlink)^.llink:=p; p^.rlink:=(p^.rlink)^.rlink;`
    > （D）`p^.rlink:=(p^.llink)^.llink; p^.llink:=(p^.rlink)^.rlink;`
    > 解析：删除 = 让**前驱跨过 p**（前驱的右链指向 p 的后继）+ **后继跨过 p**（后继的左链指向 p 的前驱），其余选项都错误地修改了 p 自身的链域（p 即将被释放，改它没有意义）。

### 简答题（含标准答案）

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【简答 1】两种存储结构的选择</b></p>

线性表有两种存储结构：一是顺序表，二是链表。试问：

1. 如果有 n 个线性表同时并存，并且在处理过程中各表的长度会动态变化，线性表的总数也会自动地改变。在此情况下，应选用哪种存储结构？为什么？
2. 若线性表的总数基本稳定，且很少进行插入和删除，但要求以最快的速度存取线性表中的元素，那么应采用哪种存储结构？为什么？

**【标准答案】**

1. 选**链式存储结构**。链表可**按需动态申请和释放**结点空间，不受表长度变化的影响，长度增减只需修改指针；且定位后的插入、删除时间复杂度为 O(1)。若用顺序表，则必须按最大可能的表长预分配空间，n 个表并存时空间浪费严重且难以伸缩。
2. 选**顺序存储结构**。顺序表支持**随机存取**，按位存取任一元素的时间复杂度为 O(1)；而链表只能从头逐个查找，O(n)。很少插删则顺序表"插删要移动元素"的缺点基本不构成影响。
</div>

<div style="background:#e8f2fb;border:1.5px solid #1565c0;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1565c0;">【简答 2】单链表设置头结点的作用</b></p>

**【标准答案】** 在单链表的首元结点（第一个数据元素结点）之前附设的结点称为**头结点**。其作用是：

1. 使**空表与非空表的处理统一起来**（空表时头结点的 `next` 为 NULL，与非空表首元插入逻辑一致）
2. 使**首元结点与其他结点的操作统一起来**——任何位置的插入/删除都归结为"修改前驱结点的指针"，无需对首元结点单独判断并修改头指针，简化了算法
</div>

### 两章高频易错点总清单

<div style="background:#fef3de;border:1.5px solid #d6740e;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#d6740e;">【考前 10 分钟必读】按坑出题频率排序</b></p>

1. <b style="color:#c62828;">五大特性 ≠ 四个要求</b>：正确性、可读性、健壮性、高效性是**设计要求（评价标准）**，不是算法特性——选择题头号坑
2. <b style="color:#c62828;">输入 0 个或多个、输出 1 个或多个</b>："算法必须有输入"判 ❌，"必须有输出"判 ✅
3. <b style="color:#c62828;">程序 ≠ 算法</b>：程序（如操作系统）可以不满足有穷性，算法必须有限步结束
4. <b style="color:#c62828;">运算定义看逻辑结构、运算实现看存储结构</b>：判断题常把两者对调
5. <b style="color:#c62828;">逻辑结构可多对多地对应存储结构</b>：线性表既可以顺序存储（顺序表）也可以链式存储（链表），但接口不变
6. <b style="color:#c62828;">链表插入删除 O(1) 有前提</b>（已知前驱）；需先查找时总复杂度 O(n)；单链表**不支持随机存取**
7. <b style="color:#c62828;">顺序表的插入范围 1 ≤ i ≤ n+1，删除范围 1 ≤ i ≤ n</b>；插入平均移动 n/2 个、删除平均移动 (n−1)/2 个元素
8. <b style="color:#c62828;">位序从 1 开始、数组下标从 0 开始</b>：位序 i ⇔ 下标 i−1，代码题笔误重灾区
9. <b style="color:#c62828;">头结点 ≠ 头指针 ≠ 首元结点</b>：头指针恒不为空；带头结点时单链表判空是 `L->next==NULL`，循环链表判空是 `L->next==L`
10. <b style="color:#c62828;">头插法建表得到逆序，尾插法得到正序</b>；尾插法最后必须 `r->next=NULL`
11. <b style="color:#c62828;">双向链表插入 4 句的顺序</b>：先把新结点 s 的 `prior/next` 接好，再让 `p->next->prior=s`，最后才 `p->next=s`，提前最后一步必断链
12. <b style="color:#c62828;">平均 ≠ 最坏时间复杂度</b>：快排平均 O(n·log n)、最坏 O(n²) 是填空题最爱
13. <b style="color:#c62828;">空间复杂度只算"额外"空间</b>：原输入数据本身不算；原地工作 S(n)=O(1)；递归空间 ≈ 递归深度
</div>

### 简答题背诵清单（直接照背）

<div style="background:#e8f7ed;border:1.5px solid #1e8449;border-radius:8px;padding:12px 16px;margin:12px 0;">
<p style="margin:0 0 6px 0;"><b style="color:#1e8449;">【简答题速答卡】</b></p>

1. **算法的五大特性**？——有穷性、确定性、可行性、输入（0 或多个）、输出（1 或多个）
2. **算法设计的四个目标**？——正确性、可读性、健壮性、高效率与低存储量需求
3. **数据结构三要素**？——逻辑结构、存储结构、数据运算（定义基于逻辑结构，实现基于存储结构）
4. **ADT 三元组**？——数据对象 D、数据关系 S、基本操作 P；与具体实现无关
5. **头结点的作用**？——统一空表与非空表的处理；使首元结点的插删无需特殊处理
6. **顺序表的优缺点**？——优点：随机存取 O(1)、存储密度高；缺点：插删平均移动 n/2 个元素、需预分配空间
7. **链表的优缺点**？——优点：插删已定位处只改指针 O(1)、按需分配空间；缺点：不能随机存取、存储密度低
8. **循环链表 / 双向链表分别解决什么**？——循环：从任一结点可遍历全表（带尾指针可 O(1) 访问头尾）；双向：O(1) 找前驱
